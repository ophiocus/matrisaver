# Iconic Matrix scenes — overlay queue source list

Curated from a **YouTube-only** search for "iconic matrix scenes" (+ a
scene-specific pass). This is the shot list for the per-variant overlay
queues (`assets/overlays/<variant>/`): which scenes to source, ranked by
iconicity **and** silhouette/colour readability (a strong, recognizable
pose reads best as code).

> **Sourcing protocol.** These are Warner Bros. frames. Pull reference
> stills **dev-only** (gitignored, like `bane/`), run them through the
> mask pipeline (`scripts/bane_mask.py`; keep colour for the sampled-
> colour film variants), and **replace with original silhouette art
> before any release tag** (Rogers-v-Grimaldi path — see
> `memory/licensing_decisions.md`). The list below is references, not media.

Ranking key: ★★★ = franchise-defining / drop-in first, ★★ = strong,
★ = nice-to-have.
